# bothy.systems

We build the platforms that run national governing bodies of sport: members, clubs, events and rankings.

- **Membership:** joining, renewals, families, and the cards members carry
- **Clubs and people:** affiliation, club officers, coaches, and the registers behind them
- **Events:** calendars, entries, payments, and results
- **Rankings:** calculated from the results, published as they change

## How we work

A bothy is a mountain shelter, open to anyone who walks in and kept up by the people who use it. Its code is short: respect the place, leave it better than you found it, look after whoever comes next. We build the same way.

- **It's yours.** The data, the code and the accounts belong to the governing body, and it can take them elsewhere.
- **Leave it better.** Every change is tested, documented, and easy for the next person to pick up.
- **Built to last.** Secure by default, backed up, monitored, and run in the UK.
